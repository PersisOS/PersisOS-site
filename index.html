PersisOS v2.0

Modern. Elegant. Open Source.

A lightweight operating system powered by KDE Plasma with minimal footprint, multi-arch support (amd64/arm64), and a headless server edition.

Download v2.0-test-2 GitHub Repo Support on Daramet

KDE Plasma

Clean and fluid modern desktop interface replacing the previous XFCE base.

Debian 13 Base

Built upon Debian Trixie for stable yet updated packages and kernel stack.

amd64 & arm64

Fully supported across standard x86 computers and modern ARM64 devices.

Headless Server

A stripped-down profile designed for lightweight virtualization and servers.

# 1. Clone the project
git clone https://github.com/arshavirm/PersisOS.git && cd PersisOS

# 2. Build KDE Desktop ISO
sudo python3 build.py --arch amd64 --desktop plasma

# 3. Build Headless Server Profile
sudo python3 build.py --profile server
